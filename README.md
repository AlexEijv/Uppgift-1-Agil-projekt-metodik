
# User-stories:

# Allmänt:

- [ ] Som besökare vill jag kunna se en attraktiv och informativ startsida så att jag snabbt kan få
en överblick över restaurangen.

- [ ] Som besökare vill jag att webbplatsen

# Meny-del: 

- [ ] Som besökare vill jag kunna se restaurangens meny online så att jag kan avgöra om det finns
något jag vill beställa innan jag besöker restaurangen.

# Kontaktformulär-del:

- [ ] Som besökare vill jag kunna fylla i ett kontaktformulär så att jag enkelt kan ställa frågor eller
ge feedback till restaurangen.

- [ ] Som besökare vill jag ha en bekräftelse på att mitt meddelande har skickats, så att jag vet att
restaurangen har mottagit min fråga (kan vara till en annan sida).

# Öppettider och Kontaktinformations-del:

- [ ] Som besökare vill jag kunna se restaurangens öppettider och kontaktinformation på varje
sida så att jag lätt kan hitta den informationen.

- [ ] Som besökare vill jag kunna klicka på en länk för att enkelt öppna min kartapp och få
vägbeskrivningar till restaurangen.
